# スマホアプリ「LED現調」の公開手順

スマホのカメラと「圏外でも起動する仕組み」を使うため、アプリは `https://` で始まるアドレスで公開する必要があります。
公開するのは `dist` フォルダの中身（5ファイル）だけです。調査データはスマホの中にだけ保存され、公開先には送られません。

## 方法1：Netlify Drop（いちばん簡単・無料）
1. パソコンのブラウザで https://app.netlify.com/drop を開き、無料アカウントでサインインする
2. `dist` フォルダをそのまま画面にドラッグ＆ドロップする
3. 表示された `https://～.netlify.app` のアドレスを調査員に送る（サイト名は設定で変更できる）

## 方法2：GitHub Pages（無料）
1. GitHub でリポジトリを作り、`dist` の中身をアップロードする
2. Settings → Pages で公開する（無料プランではリポジトリを公開にする必要がある。アプリ本体と施設名・器具マスタが公開される点に注意）

## 方法3：社内のWebサーバー
`dist` の中身を置き、https で配信する。

## マスタを直したとき
`survey123_form/media` の CSV を直したら、`python build_app.py` を実行して `dist` を作り直し、公開し直す。
スマホ側はアプリを開き直すと新しい版に入れ替わる（入力済みのデータは消えない）。

## 動作確認（開発者向け）
- `python tests/e2e_test.py dist 出力フォルダ`：スマホ画面サイズの Chrome（疑似カメラ・マイク・GPS）で、入力→撮影→録音→書き出しまでを通しで確認
- `python tests/offline_test.py dist`：通信を切っても起動し、データが残るかを確認
